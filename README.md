# Python初学者学习项目

这是一个为Python初学者设计的学习项目，包含基础语法示例和练习。

## 项目结构

- `basic_examples.py` - 基础语法示例
- `exercises.py` - 练习题目
- `README.md` - 项目说明

## 开始学习

1. 安装Python 3.x
2. 运行 `basic_examples.py` 查看基础语法示例
3. 尝试完成 `exercises.py` 中的练习
